# 小專題題目 : 電子雞

# 遊戲規則 :
### 透過主選單進行分流，玩家可自由選擇挑戰高壓走位的「生存模式」或使用者付費的「養雞場模式」。
### 【生存模式】：引導小雞躲避四面八方襲來的彈幕，存活越久分數越高。若血量歸零則遊戲結束。
### 【養雞場模式】：佛系無壓力的養成溫室，小雞會隨機閒晃與說話，但實施使用者付費，每次餵食基礎飼料需扣除 5 元。
### 透過「商店系統」購買的特殊道具（果凍、肉乾、大補丸）可進行極端的數值拉扯，考驗玩家的資源調配。

# 程式介紹 :
### 本專案基於 C++ 語言與 Raylib 圖形函式庫開發，核心採用物件導向設計（OOP），將寵物靈魂、數值背包、局內/局外商店、結算機制完美解耦。
### 遊戲人數設定為 1 人，具備以下三大技術亮點：
### 1. 雙獨立寵物實體：生存戰鬥雞與農場養成雞擁有 100% 獨立的名字、存活時間與狀態（飢餓、心情、血量），互不干涉。
### 2. 全球中央錢包：全遊戲共享同一個金幣庫。在生存模式大賺的血汗錢，能即時同步至養雞場供玩家揮霍。
### 3. JSON 進度持久化：引入 `nlohmann/json` 架構，在商店交易、遊戲破紀錄、或是關閉視窗的瞬間，自動將雙雞數值與庫存加密寫入 `data.json`，重開遊戲也可讀檔保存。

# 基本玩法 :
## * 公共規則 :
* 兩大模式金幣共享，金幣可用於商店採購食物或於基因研究院進行永久升級。
* 遊戲內建 4 種食物：
  * **基礎飼料**：生存模式免費，養雞場模式每口扣除 $5 金幣。
  * **極樂果凍**：心情全滿，但具副作用（扣 25% 飽食、扣 20% 血量）。
  * **魔能肉乾**：飽食全滿，但具副作用（扣 25% 心情、扣 20% 血量）。
  * **精煉大補丸**：血量回復 10 滴，但引發嚴重虛弱（飽食與心情各扣 50%）。

## * 彈幕生存模式 :
* 小雞會強制跟隨滑鼠指標進行高壓走位。
* 隨著存活秒數增加，怪獸生成間隔會動態縮短（最快 0.4 秒一隻），且移動速度會不斷飆升。
* 戰場隨機孵化具備鎖定功能的「紅色追蹤彈」，會即時修正方向朝寵物刺過來。
* 死亡時觸發結算，將存活秒數轉換為金幣，並可按下 **U鍵** 進入「基因研究院」永久升級各項最大屬性上限。
* 遊戲結束後按下 **ENTER鍵** 即可安全清理戰場、清空怪獸並優雅退回主選單。
## * 結算機制  :
* 存活時間每 1 秒，依據 RewardManager 權重公式轉換為對應倍率的金幣。
* 破紀錄時，系統將自動將最新秒數寫入 `highScore` 欄位更新歷史最高紀錄。

## * 養雞場模式 :
* 沒拿食物時，小雞自動啟動隨機 wanderTimer，在 960x540 的畫布裡無壓力閒晃、自言自語。
* 滑鼠手上拿著飼料時，小雞才會轉為跟隨狀態，且必須親自走到滑鼠方圓 40 像素內才能吃食。
* 小雞體型會根據該模式累積的存活時間「感官膨脹」，最高可膨脹至 2.5 倍的巨型神獸！
* 內建「隨時改名」機制，點擊右上角按鈕即可為養成雞更換專屬稱號，且不會干涉生存模式的名字。

# 程式如何安裝執行：
### * 下載專案原始碼 ZIP 檔。
### * 解壓縮 ZIP 檔案。
### * 點擊開啟 `Game-develop` 。
### * 初次使用時請確保 `data.json` 與 `savegame.json` 已經刪除，如果沒有請手動刪除
### * 點擊 `game.exe` 啟動遊戲 。
