​📖 程式介紹 (Introduction)
​本專案是一款使用 C++ 與 Raylib 遊戲引擎 開發的 2D 桌面電子雞互動遊戲。
程式架構嚴格遵守「物件導向程式設計 (OOP)」原則，具備以下技術亮點：
​狀態機架構 (State Machine)：完美分離「命名畫面」與「遊玩畫面」，遊戲邏輯清晰不衝突。
​組合模式 (Composition)：將「數值管理 (PetStats)」從實體中抽離，作為背包裝備在寵物身上，符合單一職責原則 (SRP)。
​人工智慧與向量數學 (Vector Math)：利用 Raymath 實作寵物的「隨機閒晃 (Wander AI)」與「精準追隨 (Follow AI)」平滑移動邏輯。
​動態字型快取：載入客製化中文字庫，支援即時的鍵盤輸入與動態對白生成。

​🎮 遊戲規則與玩法 (Gameplay & Rules)
​遊戲規則
​生命維持：電子雞擁有「飢餓度」與「心情值」兩項基本數值。隨著遊戲時間流逝，數值會每秒自動下降。
​餵食機制：玩家必須適時餵食電子雞。當電子雞順利吃到飼料時，飢餓度與心情值會瞬間恢復。
​自由度：玩家可以隨時為電子雞重新命名，遊戲會即時更新角色的專屬對白。
​具體玩法
​初始命名：遊戲啟動後會進入命名畫面，請使用鍵盤輸入寵物的名稱（支援英文與數字，最多 12 字元），輸入完畢後按下 Enter 鍵進入遊戲。
​隨機閒晃：在平時沒有指令的狀態下，寵物會在視窗內自由散步。
​餵食互動：
​點擊畫面左上角的 「飼料」 按鈕，滑鼠游標會變成一顆橘色飼料。
​寵物會立刻被飼料吸引並朝滑鼠方向走過來。
​當寵物碰到滑鼠（飼料）時，進食成功！數值血條將會上升，飼料狀態自動解除。
​修改名稱：點擊左上角的 「改名」 按鈕，遊戲會暫停並回到命名畫面，重新輸入後即可賦予寵物新名字。
